# Module 03.2 - Advanced Search & Source Selection 🔍

An interactive, high-impact web presentation and animation suite designed for the **Foundation Diploma in Digital Technology & ICT**. This project transforms abstract search concepts and evaluation criteria into engaging visual animations optimized for 86" smartboards and standard displays.

## 🚀 Key Features

* **Interactive Step-by-Step Animations:** Click-driven state transitions that visualize complex network algorithms and search mechanics.
* **Pure Web Technologies:** Built with native HTML5, CSS3 (Keyframes & Grid/Flexbox), and Vanilla JavaScript—no external frameworks or heavy libraries required.
* **Fully Responsive Design:** Features fluid scaling and custom mobile/laptop fallbacks to ensure seamless rendering across any screen resolution.
* **Classroom-Ready UI:** Dark-mode optimized with futuristic glowing interfaces, laser effects, and particle simulations to maximize student engagement.

---

## 📚 Modules & Visualizations Included

1. **The Search Filter Algorithm:** Visualizes how search engines process millions of raw results through operator funnels and laser filtering.
2. **Exact Phrase Match (`""`):** A magnetic alignment animation demonstrating how quotation marks lock scattered keywords into a single precise phrase.
3. **The Exclusion Operator (`-`):** A live conveyor belt simulation with a security laser gate that vaporizes unwanted results (e.g., `-degree`).
4. **The Domain Filter (`site:`):** Illustrates network routing shifts from blind open-web broadcasting to targeted server connections (e.g., `.gov.lk`).
5. **The File Type Extractor (`filetype:`):** A radar/extractor hub that cleans up mixed search spaces to isolate specific document formats like `.pdf`.
6. **The Truth Scanner (Source Selection):** An X-ray machine simulation evaluating information reliability based on Authority, Currency, Accuracy, and Purpose (CRAAP Test).
